# Происхождение дополнений AniMPV

Дополнения в `scripts/animpv/`, их конфигурация, тесты и панель написаны для AniMPV. Код, настройки, тексты, шрифты и оформление сборки Adventurer Kun в поставку не включены. Её пользовательские возможности использованы как ориентир требований; некоторые скрипты ранее изучались, поэтому разработка не называется «чистой комнатой».

Основа репозитория — [mpv](https://github.com/mpv-player/mpv), с сохранёнными сведениями об авторах и лицензиями в корне. Новые дополнения распространяются на условиях GPL-2.0-or-later; см. `../LICENSE.GPL`.

Первая версия не содержит uosc, thumbfast, Lua-модулей или графических ресурсов сторонних сборок. Используются официальные API mpv и системный шрифт Segoe UI (шрифт не распространяется в пакете). На Windows LuaJIT FFI вызывает системные функции проверки ссылок на каталоги.

Исполняемый mpv предоставляется отдельно. Для тестов можно явно указать существующий движок; он запускается с изолированной конфигурацией, без дополнений из его прежней папки. Для выпуска требуется отдельно зафиксировать источник, версию и контрольную сумму бинарного движка и его зависимостей.
