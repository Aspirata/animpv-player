# AniMPV

Самостоятельные дополнения к mpv для просмотра аниме. Доступны компактная панель с иконками и превью перемотки, меню, внешние дорожки, порядок серий, выбор озвучки, история и ручное продолжение просмотра. Исходники движка mpv не изменены.

Текущая версия — рабочая основа с базовым функционалом, пригодная для повседневного использования. Интерфейс пока предварительный: его внешний вид и организация будут заметно меняться в следующих версиях.

## Запуск на Windows

Нужен standalone mpv **0.39 или новее с LuaJIT**. Собранный движок в репозиторий не включён.

В текущей рабочей папке уже подготовлен отдельный движок в `bin/`: можно сразу запустить `Start-AniMPV.cmd`. Его версия, источник и SHA-256 записаны в `runtime.json`. `bin/` исключён из Git; после нового клонирования выполните шаги ниже.

1. Поместите mpv и необходимые ему библиотеки в `animpv/bin/`. Также можно задать переменную `ANIMPV_MPV` полным путём к существующему `mpv.exe` или установить mpv в PATH.
2. Откройте `Start-AniMPV.cmd` либо перетащите на него видео. В открытое окно также можно перетащить файл.
3. Для PowerShell: `./Start-AniMPV.ps1 -MpvPath 'C:/Tools/mpv/mpv.exe' 'D:/Anime/Show - 01.mkv'`.

Запуск использует только конфигурацию этой папки. Настройки обычного mpv и исходная референсная сборка не изменяются. Папка должна быть доступна для записи истории и скриншотов. Установка, регистрация расширений и скачивание компонентов не выполняются.

## Управление

| Действие | Управление |
| --- | --- |
| Плей/пауза | Пробел, один левый клик по видео или кнопка на панели |
| Перемотка на 5 секунд | ← / → |
| Громкость | ↑ / ↓ |
| Предыдущая / следующая серия | PgUp / PgDn |
| Аудио / субтитры | A / J |
| Плейлист / история | P / H |
| Продолжить с сохранённой позиции | Ctrl+R |
| Полный экран | F, двойной левый клик по видео или кнопка на панели |
| Выключить звук / скрыть субтитры | M / V |
| Повторить поиск дорожек | F5 |
| Показать панель / справку | Tab / F1 |
| Главное меню | Кнопка меню на панели или правый клик |
| Выбор в меню | ↑ / ↓, Enter, Esc |

Одиночный клик по видео срабатывает после короткого ожидания второго клика. Пробел и кнопка плей/паузы на панели действуют сразу.

В настольном AniMPV для Windows буквенные сочетания из таблицы привязаны к позициям клавиш QWERTY. Например, меню аудио открывает клавиша **A/Ф**, а продолжение работает через **Ctrl+R/К**. Плеер подхватывает смену раскладки в открытом окне. Явные назначения в `input.conf` имеют приоритет над этими стандартными сочетаниями. Раскладки, которые не передают mpv различимые символы (например, отдельные режимы IME), могут требовать ручных назначений.

Шкала времени поддерживает нажатие и перетаскивание, показывает маркеры глав и доступный буфер. Над шкалой отображается название главы, которая сейчас воспроизводится. При наведении карточка показывает миниатюру, время и название главы под курсором. У главы без названия отображается её номер. Иконки имеют текстовые подсказки; в узком окне часть кнопок доступна через главное меню и горячие клавиши. Колесо над шкалой перематывает; над панелью меняет громкость, в меню перемещает выбор. Панель и курсор скрываются вместе через 2 секунды бездействия на паузе и через 1 секунду при воспроизведении. Таймер считается от последнего действия, независимо от штатной настройки автоскрытия курсора. Движение мыши, Tab и смена режима плей/пауза показывают её снова и запускают новый отсчёт. Открытое меню и перетаскивание шкалы удерживают панель и курсор на экране; неподвижное наведение отсчёт не продлевает. Остальные стандартные клавиши mpv остаются доступны.

В меню по правому клику подсвечивается пункт под мышью. Цветная полоска слева отмечает пункт, который откроется по Enter. Если список не помещается, его можно прокрутить колесом или клавишами.

Превью включено для локальных видео. Кадры декодирует отдельный экземпляр того же mpv без конфигурации и скриптов; FFmpeg как отдельная программа не нужен. Нужен движок с поддержкой кодирования rawvideo (подготовленный `bin/` подходит). По умолчанию: задержка наведения 120 мс, шаг кадров 2 секунды, до 16 кадров в кеше, один декодер одновременно и тайм-аут 5 секунд. При уходе курсора, открытии меню и смене файла работа отменяется. Временные кадры удаляются после бездействия и при штатном выходе. Пока кадра нет, подсказка сразу показывает время и полное название главы с переносом строк.

Параметры находятся в `script-opts/animpv.conf`: `ui_scale` — масштаб панели; `previews=no` — отключить изображения; `preview_delay` — задержка 0.12–1 с; `preview_cache` — 1–32 кадра; `preview_mpv` — необязательный путь к другому движку. На многочасовых или тяжёлых файлах первый кадр может появиться с задержкой. Превью не воспроизводит пользовательские фильтры и настройки цвета основного видео.

## Дорожки, серии и история

Поиск начинается в папке открытого видео и идёт вниз в пределах настроек `script-opts/animpv.conf`: глубина 3, до 128 каталогов и 4000 записей. Индекс повторно используется 30 секунд; F5 сбрасывает его. На Windows ссылки и junction-каталоги пропускаются. Без проверки ссылок вложенный поиск отключается с объяснением. Отдельное чтение каталога средствами mpv остаётся синхронным: медленный сетевой диск может задержать ответ.

Точные имена имеют приоритет; поддержаны явные `S01E02`, `1x02`, `Название - 02`, `Название [02]` и номер в конце имени. Разрешение, год и CRC не используются как номер серии. Название сериала и сезон должны совпадать; файлы с одним номером без названия допускаются как внешние дорожки. Произвольные схемы наименования могут потребовать ручного подключения стандартными средствами mpv.

Несколько равноправных дорожек одной группы и разные версии эпизода доступны в меню **«Варианты файлов»** для ручного выбора. Пункт появляется только при наличии таких вариантов. Автоматический плейлист содержит только видео из текущего каталога и не заменяет уже переданный плейлист. OP/ED с явными латинскими обозначениями исключаются из распознанной последовательности. Если номер не распознан, используется обычный список видео с естественной сортировкой.

Распознанные эпизоды в меню начинаются с номера: **«Серия 03 · Название эпизода»**. Повторяющееся длинное имя сериала и технические теги файла не занимают начало строки. Для следующих сезонов используется обозначение вида **S02E03**; если нумерация не определена, остаётся исходная подпись.

Названия внешних дорожек включают папку группы и метаданные каждого потока; многодорожечные MKA сохраняют отдельные варианты. Выбор через меню AniMPV переносится на следующую серию по группе, языку и названию, а не по временному номеру дорожки.

Видео открывается с начала. История предлагает продолжение через Ctrl+R. Простое открытие/закрытие в начале не стирает старую позицию. История хранится локально в `state/`; полезная позиция обновляется не чаще заданного интервала и при завершении. По умолчанию показывается до 300 записей. Каждое окно пишет собственный журнал; чтение объединяет до 32 наиболее свежих журналов, старые неактивные журналы сверх этого числа очищаются после суток. Повреждённые строки пропускаются. Данные об истории никуда не отправляются.

## Границы версии

Это основа плеера с первым набором медиаинструментов. Инструменты буфера обмена, меню онлайн-форматов, экспорт клипов, корзина, установщик и обновлятор ещё не реализованы. Наличие штатной поддержки URL в mpv не означает проверенную интеграцию онлайн-сервисов AniMPV.

В первую очередь проверяется Windows x64. Linux/macOS и разные видеокарты/дисплеи пока не подтверждены. Правила требуют измерений на реальных раздачах; производительность не объявляется выше других сборок без сравнения.

## Проверки для разработчика

Только для тестов нужны Python 3.10+ и, для интеграции, FFmpeg в PATH:

```text
python animpv/tests/run.py --mpv C:/Tools/mpv/mpv.exe
python animpv/tests/integration.py --mpv C:/Tools/mpv/mpv.exe
python animpv/tests/visual.py --mpv C:/Tools/mpv/mpv.exe
python animpv/tests/previews.py --mpv C:/Tools/mpv/mpv.exe
python animpv/tests/keyboard.py --mpv C:/Tools/mpv/mpv.exe
python animpv/tests/autohide.py --mpv C:/Tools/mpv/mpv.exe
```

Модульные проверки выполняют настоящий Lua-код внутри чистого mpv. Интеграция создаёт синтетические видео, двухдорожечные MKA и субтитры, затем проверяет поведение по IPC. Визуальная проверка открывает окно с синтетическим видео. Реальные раздачи и изображения из сторонних сборок в тесты не включены.
