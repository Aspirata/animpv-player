# AniMPV

**Русский** | [English](README.en.md)

AniMPV — форк [mpv](https://github.com/mpv-player/mpv) с самостоятельными дополнениями для просмотра аниме. Проект развивает собственный интерфейс и инструменты для работы с сериями, внешними дорожками и историей просмотра.

## О проекте

AniMPV вдохновлён отличной сборкой Adventurer Kun и развивает схожие идеи. Проект появился из желания сделать их доступными на разных платформах, исправить некоторые недоработки и развивать более открытый проект с открытым исходным кодом.

AniMPV — самостоятельная альтернатива с иной реализацией и собственным итоговым видом. Проект не позиционируется как «улучшенная» версия или прямая замена сборки Adventurer Kun.

## Возможности

- Компактная панель управления, меню и превью при перемотке.
- Поиск внешних аудиодорожек и субтитров, выбор и сохранение озвучки.
- Автоматический порядок серий и выбор вариантов файлов.
- Локальная история и продолжение просмотра по запросу.

## Состояние проекта

Базовые функции доступны для использования. Интерфейс предварительный и будет перерабатываться. В первую очередь проект проверяется на Windows x64; работа на Linux и macOS пока не подтверждена. Установщик, обновлятор и ряд дополнительных медиаинструментов ещё не реализованы.

## Запуск

В релизах планируется распространять AniMPV как готовую к использованию сборку с движком mpv.

При запуске из исходного репозитория движок нужно предоставить отдельно: поместите standalone mpv с LuaJIT и необходимыми библиотеками в `animpv/bin/`, укажите путь через `ANIMPV_MPV` или добавьте mpv в PATH. Проверки проводились с mpv 0.39 и 0.42. Затем запустите `animpv/Start-AniMPV.cmd` или перетащите на него видео.

Подробные инструкции, управление, ограничения и команды проверок находятся в [руководстве AniMPV](animpv/README.md).

## Версии

Название релиза имеет вид **AniMPV vX — vY**: первое число обозначает версию AniMPV, второе — версию включённого движка mpv. Например, `AniMPV v1 — v0.42.0-11`: `v1` — версия AniMPV, а `v0.42.0-11` — сборка mpv после релиза 0.42.0.

Версия AniMPV увеличивается целым числом при изменениях проекта; при обновлении только движка меняется его обозначение. В дальнейшем планируется использовать стабильные релизы mpv. Для сборки между релизами полная версия с идентификатором коммита, источник и контрольная сумма указываются в сведениях о релизе. Для Git-тега используется формат `v1_v0.42.0-11`.
